# 首页千问事务录入

在首页直接发文字，例如：

> 10月8日早上10点半星璇智能面试；10月18日下午1点国安双选会。我的主线是搭建系统、准备国考、找工作、写大论文。

千问先判断领域，再读取真实主线/项目候选并整理事务。此时没有写入数据库。

## 确认前

- 检查每张卡片的类型、名称、归属、日期、上海时间。
- 没写年份的日期按当前上海年份推断，需勾选确认，或修改计划日期。
- 语义相似的主线/项目只是复用建议，必须确认。复用不修改旧记录。
- 行动可以独立存在；也可以选择真实项目，或点击“添加项目”并自己填写成果。不自动编造项目。
- 同名行动会提示重复，可选择仍然新建或跳过。
- 长期主线不会自动成为发金币的核心行动；主动勾选核心后必须填写目标和完成条件。
- 不完整项可以跳过；其子项需要重新选择归属，不能带着失效父级保存。

## 保存与失败

点击“确认保存 N 项”后按依赖顺序逐项调用现有 RPC，父级先保存，再把真实回执 ID 传给子项。整批不是一个原子事务。

已保存项显示真实回执及查看链接，不重复创建。明确失败暂停队列，可以原请求重试，或结束原批次，仅修改未保存项。结果未知必须保留页面并使用原请求重试核对；此时不能重新生成、修改、开启其他批次或离开。未知结果的后续拒绝不会被误当作首次提交没有保存。

不要强制刷新未知结果页面。浏览器无法保证阻止强制关闭；本版不在本地持久化批次，刷新后请先核对真实记录，避免重新发同一段话。

## 范围和部署

只支持新建主线、项目、行动、收集内容，或确认复用主线/项目。财务入口保持可用，但财务和事务混合在一句时需分开发送。暂不支持事务编辑、完成、进展、金币操作或通知。

计划日期写入现有 `due_date`；具体时间以 `计划时间：YYYY-MM-DD HH:mm（Asia/Shanghai）` 保存在说明中，不是日历提醒。

不需要执行新 SQL，也没有新增环境变量。继续复用服务端 `DASHSCOPE_API_KEY`、`QWEN_BASE_URL`、`QWEN_MODEL`，以及公开 Supabase URL/publishable key、Auth cookie、RLS。密钥不发给浏览器。
